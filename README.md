# Jean da Cultura | Landing Page

Portal oficial da campanha de **Jean da Cultura** — Deputado Distrital 43222, pelo Partido Verde, Eleições 2026.

## Como rodar localmente

**Pré-requisitos:** Node.js

1. Instale as dependências:
   `npm install`
2. Rode o app:
   `npm run dev`

O site fica disponível em http://localhost:3000.

## Scripts

- `npm run dev` — servidor de desenvolvimento (Vite)
- `npm run build` — build de produção
- `npm run preview` — pré-visualização do build
- `npm run lint` — verificação de tipos (tsc --noEmit)

## Estrutura

- `src/components/` — seções da landing page (Hero, Biografia, Cultura, Propostas, Transparência, Rodapé etc.)
- `public/` — imagens e logomarca do Partido Verde
- `src/App.tsx` — composição das seções
